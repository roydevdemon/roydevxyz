# RoyDevXyz Theme

A custom Hexo theme with clean, modern design.

## Features

- Responsive design
- Clean and minimal layout
- Syntax highlighting support
- Social links
- Archive, category, and tag pages
- Back to top button
- Code copy button

## Structure

```
themes/roydevxyz/
├── _config.yml          # Theme configuration
├── layout/              # Layout templates
│   ├── layout.ejs       # Base layout
│   ├── index.ejs        # Home page
│   ├── post.ejs         # Post page
│   ├── page.ejs         # Page layout
│   ├── archive.ejs      # Archive page
│   └── partials/        # Reusable components
│       ├── head.ejs     # HTML head
│       ├── header.ejs   # Site header
│       └── footer.ejs   # Site footer
├── source/              # Static assets
│   ├── css/
│   │   └── style.css    # Main stylesheet
│   └── js/
│       └── script.js    # Main JavaScript
└── README.md
```

## Customization

Edit `themes/roydevxyz/_config.yml` to customize:
- Menu items
- Social links
- Favicon
- Widgets

Edit `themes/roydevxyz/source/css/style.css` to customize colors and styles.

## Development

The theme is designed to be easily customizable. Feel free to modify any files to suit your needs!
